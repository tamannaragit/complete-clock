# Clock App (React + Vite)

## Setup
1. Install Node.js from https://nodejs.org (LTS) if not already installed.
2. Extract this folder anywhere, e.g. `C:\Users\Admin\Desktop\Shatakshi\clock-app`
3. Open a terminal in that folder and run:
   ```
   npm install
   npm run dev
   ```
4. Open the URL shown in the terminal (usually http://localhost:5173) in your browser.

## Features
- Analog clock (SVG, live-updating hands)
- Digital clock (12-hour format with date)
- Stopwatch (start/pause/reset/lap)
- World clock (New York, London, Mumbai, Dubai, Tokyo, Sydney — live, updates every second)
